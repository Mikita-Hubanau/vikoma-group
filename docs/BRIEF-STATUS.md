# Статус подробного ТЗ

## Выполнено в коде и данных

Общие требования: кликабельные контакты, партнёрские адреса, имена команды,
отсутствие публичных ссылок /admin, единый правый текст H1 с исключением контактов.
Сохранён только второй макет Balance во всех языках и в автономном превью.

Главная: H1/H2, «Кто мы» из трёх абзацев, две услуги с иконками и списками,
четыре преимущества, серый блок для белорусских компаний, партнёры, два CTA.
Услуги: два направления, партнёры, серый экспертный блок, пять шагов, CTA.
О нас: новые тексты, три человека с указанными биографиями, места для круглых
фото 200×200, сеть специалистов, партнёры, CTA.
Мероприятия: компактный H1, регистрация сверху, две бесплатные отметки,
дата/время/формат/языки/длительность, четыре результата, три группы программы,
оговорка о корректировке, сохранённая регистрация, CTA.
Контакты: новый текст, обязательные поля с проверками, восемь вариантов,
обновлённая седьмая тема, 24 часа, скрытый Telegram, без городов и офисов.

## Материалы, которых не было в архиве

1. Фотографии Марио Убальди, Виктории Губановой и Ольги Скребневской.
   Пока показаны инициалы. Фото можно загрузить через CMS в карточки команды
   либо добавить в `src/assets/media/team/`, прописав `/media/team/имя.jpg`
   в `src/content/pages/{ru,it,en}/about.json` → team.people[].photo.
   Обрезка круглая, 200×200; лучше исходник не меньше 400×400.

2. Официальные графические логотипы НАИП и «СДЕЛКИ В ПЛЮС».
   Пока выведены текстовые названия и настоящие ссылки — это НЕ логотипы.
   Загрузить файлы в CMS → Общее → Партнёры либо в `src/assets/media/partners/`
   и прописать путь в settings/{ru,it,en}.json → partners[].logo.
   Поддерживаются SVG и изображения. Без файлов визуальный пункт ТЗ о логотипах
   нельзя считать завершённым.

3. Исходный раздел «Для кого мероприятие».
   Такого раздела в предоставленном проекте нет. Его содержание не выдумано.
   В CMS и JSON мероприятий добавлены audience.title и audience.paragraphs.
   После заполнения блок автоматически появится перед «Что вы получите».

4. LinkedIn/Telegram URL.
   LinkedIn пока неактивный текст, Telegram скрыт. Указание согласованной
   HTTPS-ссылки в настройках включает соответствующую ссылку. Контакты берут
   общий список социальных ссылок из русской записи настроек.

## Неоднозначность программы

В ТЗ упоминаются шесть существующих пунктов. В архиве их восемь.
Сохранены все: вступление отдельно; пункты 2–4 в «Инвестиционном климате»;
5–6 в правовом/налоговом блоке; 7 в логистике; вопросы и ответы отдельно.
Нового доклада о платежах не выдумано: это название группы из ТЗ.

## Не изменялось без исходных данных

Настройки доставки писем и аналитики сохранены. Политика конфиденциальности
и реквизиты не сочинялись; существующие предупреждения о пустой полной политике
остаются. Обновление PHP на реальном сервере и фактическое получение письма
нужно проверить отдельно. Публикация на GitHub из этой среды не выполнялась.
