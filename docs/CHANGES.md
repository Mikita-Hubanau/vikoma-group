## Реализация

Существующий проект не заменён новым стеком. Сохранены Astro, исходная система
контента, Sveltia CMS, библиотека блоков, карта и базовый визуальный язык.
Основной язык остался русским. Имя GitHub-репозитория не переименовывалось.

Реальные партнёрские логотипы не приложены: предусмотрены поля загрузки, сейчас
используются текстовые обозначения и нейтральные иконки. Для участников команды
показаны инициалы вместо вымышленных портретов.

Форма имеет поля и валидацию, договорённый формат POST, тайм-аут, защиту от
повторной отправки, honeypot и отдельные сообщения о разных ошибках. Успех
показывается только после ожидаемого подтверждения backend. Письма не
отправлялись и реальная доставляемость не проверялась.

GA4 имеет общее поле ID, баннер выбора, отключение до согласия, запоминание
выбора и отзыв через футер. Сам Google-ресурс не создавался и не подключался.
Баннер не выдаётся за готовое юридическое решение.

Для семинара используются общий файл времени, Europe/Rome, автоматическая
подстановка дат/длительности и состояния «открыта регистрация / закрыта /
семинар завершён». Обновляются также кнопки главного экрана и анонса.
Дедлайн интерпретирован как конец 28 сентября включительно; точное время
не было задано в ТЗ. Закрытие самой Google Forms — задача её владельца.

## Исправления относительно исходной версии

Устранено расхождение между тремя языками в контенте и одним языком в конфиге
Astro. Убраны из активного сайта шаблонные контакты, условные реквизиты,
старый бренд и старые маркетинговые показатели, не соответствующие новому ТЗ.

Обновлены schema и CMS-поля, добавлена страница мероприятий. Необязательные
пустые контакты, суффикс текстового факта и поле партнёра у специалистов не
мешают сохранению контента. Количество фиксированных списков ограничено в CMS.

Учтены base path GitHub Pages, языковые ссылки, canonical/hreflang/OG, robots,
sitemap и реальные адреса возврата из CMS. Добавлена генерация CNAME только
для подходящей конфигурации корневого пользовательского домена.

Старые три URL отраслей перенаправляются на услуги. Статическое перенаправление
не следует путать с серверным HTTP 301. Архивные отрасли сохранены в исходниках,
но не оставлены шестым разделом меню.

Служебные ссылки футера видны в режиме редактирования. Сам режим не является
системой доступа; каталог блоков остаётся публичным техническим адресом.

Ввод/ошибки формы, видимые фокусы, skip-link, подписи полей, live-status,
уменьшение анимаций, перенос навигации и адаптивные сетки учтены в разметке/CSS.
Полный визуальный аудит собранного сайта не выполнен из-за недоступной сборки.

## Обновление файлов

Старые 15 Markdown-файлов услуг удалены, вместо них — 5 новых на язык:

```text
01-market-research.md
02-retail.md
03-legal.md
04-payments.md
05-specialists.md
```

Папки `src/content/services/ru`, `it`, `en` при ручном переносе заменяйте целиком.
При сохранении старых файлов поверх нового набора проверка остановит сборку,
чтобы не показать пользователю дублирующиеся или старые услуги.

Зависимости и их разрешённые версии не обновлялись. В package.json/lock-файле
изменены название/версия проекта, добавлены проверки и postbuild-скрипт.
Обновлён GitHub Actions workflow; изменения репозитория, DNS и публикация
от лица владельца не выполнялись.
