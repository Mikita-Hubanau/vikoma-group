# Изменения по подробному ТЗ

Основа: предыдущий исправленный проект из этой переписки, на котором уже
исправлены тесты контактов. Данные о бизнесе, сроках работы, партнёрах и семинаре
взяты из пользовательского ТЗ; независимо не проверялись.

## Общие изменения

Оставлен только Balance. Удалены публичный переключатель, чтение старого выбора,
стили других макетов и публичные ссылки редактирования. Меню языков сохранено.
Все новые тексты доступны на RU, IT, EN. Общий правый подзаголовок добавлен на
услуги, о нас, мероприятия; на главной и контактах он отсутствует.
Телефоны/email кликабельны; партнёрские адреса заменены на адреса из ТЗ.
Виктория: «Виктория Губанова» по-русски, «Viktoryia Hubanava» на IT/EN.

## Главная

Новые H1 и H2; три абзаца «Кто мы»; CTA сразу после них и повторно внизу.
Две карточки услуг с иконками, по три действия и ссылка на соответствующего
партнёра. Четыре преимущества. Светло-серый блок для белорусских компаний.
Партнёры в ряд: поддержка настоящих логотипов, подписи, активные ссылки.
Ранее существующий анонс семинара сохранён.

## Услуги

Остались две основные услуги с текстами из ТЗ, иконками и партнёрскими ссылками.
Добавлен серый блок экспертной поддержки. Процесс работы содержит пять шагов.
Старые три услуги архивированы в данных, но больше не отображаются на странице.
Это позволяет обновить проект без ручного удаления файлов из GitHub.

## О нас

Обновлены заголовок, подзаголовок, личный рассказ о VIKUB и профессиональная сеть.
Команда расширена до трёх человек. Для каждого подготовлена круглая фотография
200×200 с загрузкой из CMS; при отсутствии фото показаны инициалы.
Добавлен общий финальный CTA, сохранён блок партнёров с новой структурой.

## Мероприятия

Уменьшен H1; вверху регистрация и некликабельная отметка бесплатного участия.
Дата — 1 октября 2026, 10:00 Europe/Rome; онлайн, IT/RU с последовательным переводом;
длительность 60–90 минут. Добавлены четыре результата участия и три тематические
группы программы. Исходные восемь тем не потеряны: введение, шесть содержательных
тем в группах и вопросы/ответы. Исходные тексты регистрации сохранены.
Отметка бесплатного участия повторена перед формой; добавлен общий CTA.

## Контакты и обработка заявок

Новые заголовок и короткий вводный текст формы. Обновлена седьмая тема списка,
под формой указаны 24 часа. Telegram скрыт до появления URL, включая подвал.
Все семь пользовательских полей обязательны; проверяются email, телефон,
пробельные значения, согласие. При неудачной отправке поля не очищаются;
ложный HTTP 200 без подтверждения JSON не принимается за успех.
Компания и тема теперь входят в серверные поля, письмо и журнал PHP.
Телефон обязателен для обращения, но остался необязательным для регистрации.
Добавлены точные разрешённые CORS-источники для vikub.com и GitHub Pages владельца.
Тексты контактов снова редактируются через JSON/CMS, а не дублируются в MJS.
Числовые контакты остаются заданы в `src/data/contacts-page.mjs` и настройках.

## Проверки и публикация

Обновлены старые тесты под новое ТЗ и добавлены регрессии. После настоящей сборки
проверяются HTML всех 15 страниц и три формы контактов до выгрузки на Pages.
Npm-зависимости, lockfile, маршруты, брендовые SVG и настройки интеграций не заменены.
