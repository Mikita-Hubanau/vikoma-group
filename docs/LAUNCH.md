## Подключение форм

CMS → **Общие подключения и служебное → Подключения** либо
`src/content/system/integrations.json`:

```json
{
  "googleAnalyticsId": "",
  "contactFormEndpoint": "",
  "registrationUrl": "",
  "registrationFormEndpoint": ""
}
```

Нужен публичный HTTPS-адрес существующего серверного обработчика. Это не email.
Сам сайт статический, сервер для хранения заявок и отправки писем в архив не
добавлен. Можно подключить совместимый сервис форм или собственный backend.
Указание адреса само по себе не создаёт аккаунт и не подтверждает доставку.

Если `registrationFormEndpoint` пуст, регистрация использует
`contactFormEndpoint`. Общий обработчик обязан различать две формы по
`form_type` и принимать соответствующие поля. Без обоих адресов регистрация
отключена. Отдельные формы удобнее разделять разными адресами.

### Контракт HTTP

Обе формы отправляют `POST`, `multipart/form-data`, `Accept: application/json`.
Заголовок Content-Type запроса устанавливает браузер вместе с boundary.
Cookies и учётные данные стороннего сервиса не пересылаются; переходы HTTP
при AJAX-отправке не принимаются. Настройте разрешённый origin/CORS своего домена.

Контактное обращение:

```text
form_type=contact_enquiry
name, email, phone, message, consent, language, _subject, _gotcha
```

Регистрация:

```text
form_type=seminar_registration
first_name, last_name, company, email, phone, consent, language
_subject, _gotcha
event_id=vikub-seminar-2026-10-01
event_start=2026-10-01T10:00:00+02:00
```

Ответ об успехе: HTTP 2xx, `Content-Type: application/json`,
`{"ok":true}` **либо** `{"success":true}`. Возвращайте его только после фактического
приёма/сохранения заявки. Код 200 с HTML или произвольным JSON не считается успехом.
Коды 400/422 показывают ошибку данных, 429 — ограничение частоты, остальные
неуспешные ответы — ошибку отправки. При тайм-ауте 15 секунд или обрыве связи
результат считается неопределённым: сервер мог принять заявку. Автоповтора нет.

На сервере обязательны собственная проверка обязательных полей, длины, email,
согласия, антиспам, ограничение частоты и срок приёма регистраций. Клиентский
honeypot и отключение кнопки не заменяют эти меры. Для надёжной дедупликации
между перезагрузками/устройствами нужен серверный механизм; текущая блокировка
повтора действует в открытой форме. Секреты SMTP/API хранятся только на сервере,
не в JSON, CMS, `PUBLIC_*` или браузерном JavaScript.

Без JavaScript настроенная форма выполняет обычный POST: проверьте, что ответ
вашего сервера понятен посетителю. Сервер обязан самостоятельно закрывать
регистрацию по дедлайну, даже если пользователь открыл старую страницу.

### Подтверждение и Zoom

После принятой регистрации выводится сообщение из ТЗ:

> Спасибо за регистрацию. Ссылка для подключения будет отправлена за 3–4 дня до семинара.

Это сообщение **не запускает автоматическую рассылку Zoom-ссылки**. Организатор
должен отправлять ссылку вручную или настроить рассылку у себя на сервере/в сервисе.
Поздние регистрации близко к дедлайну также требуют отдельной обработки.

Поле `registrationUrl` остаётся необязательным запасным переходом в существующую
Google Forms. Разрешены публичные ссылки forms.gle или docs.google.com/forms,
не ссылка редактирования. Внешняя форма должна повторять поля и подтверждение ТЗ;
права доступа, окончание приёма и рассылки контролируются отдельно от сайта.

## Семинар и дата

`src/content/system/seminar.json`:

```json
{
  "startAt": "2026-10-01T10:00:00+02:00",
  "durationMinutes": 120,
  "timeZone": "Europe/Rome",
  "registrationDeadline": "2026-09-28T23:59:59+02:00"
}
```

Время выводится в зоне Italy/Europe-Rome независимо от зоны браузера посетителя.
Длительность и дедлайн оставлены из предыдущего ТЗ. После дедлайна клиентский
скрипт закрывает регистрацию; после окончания мероприятия показывает завершение.
При изменении даты проверьте статические SEO-тексты: заменяются автоматически
только места с `{date}`/`{duration}` и значения, собранные из системного файла.

## Аналитика, данные, материалы

Введите настоящий GA ID. До согласия посетителя внешний скрипт аналитики не
загружается. В футере можно вернуться к выбору. Проверьте реальное событие в
своём ресурсе после подключения и корректное поведение при отказе.

Встроенный баннер и технический абзац о формах не являются юридическим заключением
о соответствии требованиям обработки данных. Нужна утверждённая политика с
реальным оператором, контактами, обработчиками и сроками. Утверждения об опыте,
статусе НАИП и партнёрах взяты из материалов владельца; независимой проверки
отношений и разрешений на логотипы не проводилось.

Фотографии загружайте через CMS в `src/assets/media/`; в контенте используются
пути `/media/...`. Не добавляйте случайные портреты или неофициальные логотипы.

## GitHub Pages и размещение

Workflow `.github/workflows/deploy-pages.yml` сохраняет сборку из `main`.
В нём добавлена переменная `PUBLIC_REGISTRATION_FORM_ENDPOINT`. Остальные:
`PUBLIC_CONTACT_FORM_ENDPOINT`, `PUBLIC_REGISTRATION_URL`, `PUBLIC_GOOGLE_ANALYTICS_ID`.
Непустая переменная окружения перекрывает значение JSON; пустая использует JSON.
Чтобы отключить интеграцию, очистите оба источника и пересоберите сайт.

Маршруты учитывают корневой домен и подпапку GitHub Pages. `site.config.mjs`
содержит целевой домен. Postbuild обновляет адрес CMS и управляет CNAME, как в
предыдущей версии. DNS, HTTPS, GitHub Pages, OAuth и права CMS нужно проверить
в аккаунтах владельца; никаких таких операций при подготовке файлов не было.

Патч этой редакции применяется только к предыдущему обновлённому архиву;
полный архив проекта — альтернативный способ переноса. Не применяйте оба.

## Проверка перед запуском

```sh
npm ci
npm test
npm run build
npm run preview
npm run check:launch
```

`check:launch` ожидаемо завершается с ошибкой, пока отсутствуют настоящие
интеграции, контакты и материалы. Эта команда не проверяет существование
аккаунтов и фактическую доставку. После сборки проверьте 15 языковых страниц,
пять оформлений, узкий экран, клавиатуру, реальные формы, старые адреса,
canonical/hreflang, sitemap и авторизацию в CMS. Нельзя заменять сборку и
эту проверку отдельным HTML-превью.
