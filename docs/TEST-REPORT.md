# Проверки редакции VIKUB 1.1.0

## Границы проверки

Работа выполнена с исходниками из предыдущего архива `vikub-group-updated.zip`.
Удалённый репозиторий, работающий сайт, DNS и аккаунты сторонних сервисов не
изменялись. Проверка исходников и браузерных модулей выполнена локально.

**Полная сборка Astro не подтверждена.** `npm ci` не смог получить зависимости
из npm в этой среде. Повторный `npm run build` остановился на prebuild-проверке
CMS из-за отсутствия пакета `yaml`, до запуска компилятора Astro. Подмена
зависимостей или объявление вспомогательного рендера полноценной сборкой не выполнялись.

## Проверка формы

Подтверждение появляется только при HTTP-успехе и JSON `ok:true` или `success:true`.
Проверены обязательность компании, необязательность телефона, набор передаваемых
полей, сохранение полей после ошибки, отказ на 422, неопределённый результат при
поддельном 200/сетевой ошибке, запрет отправки без endpoint и после дедлайна,
блокировка повторного запроса после принятой регистрации.

Ответы сети в тестах имитируются **в тестовом окружении**, не в рабочем коде.
Реальная доставка писем, запись в CRM/таблицу, серверный антиспам и рассылка ссылок
не проверены и без подключённого обработчика не происходят.

## Что такое HTML-превью

`VIKUB-design-preview.html` — автономный снимок шаблонов и текущего контента.
Вспомогательный инструмент прочитал поддерживаемую разметку компонентов и стили,
но не использовал настоящий Astro compiler, content loader или оптимизатор ресурсов.
Вместо пакетов шрифтов используются системные запасные шрифты. Стили компонентов
в снимке сведены для визуальной проверки; это не проверка итогового CSS-пакета Astro.

Снимок содержит все 15 страниц и настоящий JavaScript переключателя. Его отдельная
обёртка обеспечивает переходы без сервера. Дата зафиксирована до семинара только
в снимке, чтобы можно было сравнивать оформление формы позже. В исходниках
сайта время не заморожено. Реальные формы в снимке не подключены.

Для повторения проверки снимка с установленными Python, Playwright и Chromium:

```sh
python tests/preview_layout_checks.py /путь/к/VIKUB-design-preview.html
```

Для указания своего Chromium можно использовать `BROWSER_EXECUTABLE`.
Ни снимок, ни скриншоты не следует публиковать вместо собранного приложения.

## Архив и патч

Новый патч подготовлен относительно предыдущего обновлённого архива, а не
первоначального GitHub. Он проверен применением к отдельной чистой копии этой
основы; полученные файлы сверены с новой версией по SHA-256. Новый ZIP содержит
исходники, инструкции и тесты, без `.git`, `node_modules`, сборочных каталогов
и секретов окружения. Публикация не выполнялась.

## Проверить перед запуском у владельца

Обязательно выполните `npm ci`, `npm run build` и `npm run preview` в среде
с доступными зависимостями. Требуют настоящей сборки/подключений: итоговая
Astro-вёрстка и шрифты, загрузчики/схемы контента, sitemap/postbuild, размещение
в подпапке GitHub Pages, OAuth CMS, отправка обеих форм и свой ресурс GA.

Телефоны, email, URL LinkedIn/Telegram, адреса обработчиков, GA ID и окончательная
политика данных не предоставлены. Соответствующие предупреждения ожидаемы;
`npm run check:launch` намеренно возвращает ненулевой код до их заполнения.
Названия и биографии, статус НАИП, партнёрские отношения и утверждения о компетенциях
перенесены из ТЗ владельца, без независимого подтверждения извне.
