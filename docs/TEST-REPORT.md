# Проверки VIKUB 1.3.0 — логотипы и финальные правки

## Основа и ограничения

Основа — переданный `VIKUB-Signature-5-layouts.zip` (1.2.0), а не текущая
версия удалённого GitHub. Использованы предоставленные `VIKUB.svg` и
`VIKUB_V.svg`. GitHub, действующий сайт, почтовые сервисы и другие аккаунты
не изменялись. Сведения о команде, НАИП и партнёрах взяты из последнего
пользовательского ТЗ; независимая внешняя проверка не проводилась.

**Полная сборка Astro не подтверждена.** Доступ к registry.npmjs.org
не разрешается по DNS. `npm run build` остановился на prebuild-проверке CMS:
`ERR_MODULE_NOT_FOUND`, отсутствует пакет `yaml`. До компиляции Astro
выполнение не дошло. Версии npm-зависимостей и lockfile-пакетов не обновлялись;
в package-файлах изменена только версия проекта.

Всего **51 изолированная браузерная проверка**, помимо матрицы из 450
визуальных сочетаний. Матрица проверяет переполнение, число H1, повторяющиеся
ID и положение переключателей относительно языков. Она не является
оценкой всех аспектов доступности или всех реальных устройств.

Отдельно сгенерированы 22 снимка для визуального просмотра. Просмотрены
главный экран, мобильная шапка, подвал, карточки партнёров и контакты.
Размеры, контуры и цвет золота предоставленных SVG сохранены; в тёмной
версии заменён только цвет графитовых частей на светлый.

## Что подтверждает превью

Автономный HTML обновлён на основе предоставленного визуального снимка
1.2.0: заменены изменённые CSS-блоки и разметка, актуальные строки внесены
из JSON-файлов проекта. Логотипы встроены как data-ресурсы. Проверки
сравнивают видимые тексты с текущими JSON на всех языках.

Это **не компиляция Astro**. Превью не подтверждает работу контентного
загрузчика, scoped CSS после компиляции, Fontsource-шрифтов, sitemap,
postbuild или CMS OAuth. Изолированные браузерные тесты запускаются через
Chromium/Playwright с `set_content`, включая обёртку и iframe; открытие
двойным щелчком на всех ОС владельца не проверялось.

В визуальном снимке дата зафиксирована до семинара, формы отключены,
шрифты системные. В рабочем проекте сохранены настоящая логика даты и
защищённая отправка после подключения обработчика.

## Преднамеренно незаполненные значения

Телефоны, email, ссылки LinkedIn/Telegram, обработчики форм, GA4 ID и полная
политика обработки данных владельцем не предоставлены. Удаление адресов и
стендов партнёрских логотипов не считается отсутствующим материалом:
это прямое требование последнего ТЗ.

Без HTTPS-обработчиков формы не имитируют успешную отправку. Реальная
доставка писем, регистраций, рассылка Zoom-ссылок и аналитика в аккаунте
владельца не подключались и не проверялись.

## Архив и патч

`VIKUB-branded-5-layouts.zip` — полный проект. `VIKUB-brand-update.patch`
рассчитан только на `VIKUB-Signature-5-layouts.zip` (1.2.0).
В архив не входят `.git`, `node_modules`, `.astro`, `dist`, секреты или
отдельные файлы шрифтов. Патч и новый архив не нужно применять одновременно.

Перед публикацией обязательны `npm ci`, `npm run build`, `npm run preview`
в среде с зависимостями, а затем проверка настоящих форм, языков, переходов,
логотипов, favicon и пяти раскладок в готовой сборке.
