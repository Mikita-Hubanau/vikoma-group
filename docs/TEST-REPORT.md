нужен PyYAML, для браузерной — Playwright и Chromium. Они не требуются для
обычной сборки сайта и не добавлены в production-зависимости.

Повторение дополнительных проверок:

```sh
python -m pip install PyYAML playwright
python -m playwright install chromium
python tests/check_content.py
python tests/browser_checks.py
```

Для уже установленного Chromium можно задать `BROWSER_EXECUTABLE`.
Проверка полей покрывает текущий контент, но не заменяет Astro/Zod-валидацию.

## Что именно проверялось в браузере

Использовались настоящие файлы `public/scripts/contact-form.js`,
`analytics.js`, `event-state.js` и тестовые HTML-фрагменты.

Форма: выключенное состояние, обязательные поля, корректный POST-пакет,
подтверждённый успех и очистка, альтернативный контракт успеха, 400/422/429/500,
HTML и неправильный JSON с кодом 200, сеть/тайм-аут, сохранение ввода,
повторная отправка, honeypot, отклонение небезопасного endpoint.

Analytics: отсутствие вставленного Google tag до выбора, отказ, восстановление
выбора, согласие и однократная вставка, параметры конфигурации, отзыв согласия
с перезагрузкой, истёкший/повреждённый/недоступный storage, клавиатура и
возврат фокуса, событие смены выбора в другой вкладке.

Семинар: открытый/закрытый/завершённый состояния, точная граница дедлайна,
обновление при возврате на страницу, запрет позднего клика между обновлениями.

Для фрагментов формы и баннера проверено отсутствие горизонтального переполнения
на ширинах 320, 375, 768 и 1440 px. Это **не проверка всего адаптивного сайта**.

### Ограничения браузерных проверок

Браузер среды запрещает URL-навигацию. Поэтому тесты выполнялись на
`about:blank` с локальной разметкой: storage представлен тестовым адаптером,
вставка внешнего Google-скрипта перехватывается без сетевой загрузки, backend
формы заменён контролируемыми ответами. Реальные cookies, CORS, Google Analytics,
Formspree, почтовый ящик и работа разных доменов этими тестами не подтверждены.
Это проверка логики/DOM, не end-to-end тест опубликованного сайта.

При проверках дополнительно исправлен отказ от Analytics в контексте, где
недоступен API cookies: отказ больше не зависит от доступности этого API.

## Полная сборка НЕ выполнена

В рабочей среде не было установленных зависимостей проекта, а сетевой доступ
к npm недоступен. Попытка `npm ci --offline --ignore-scripts` завершилась
`ENOTCACHED` (отсутствует пакет в локальном кэше).

Попытка `npm run build` остановилась на prebuild: `ERR_MODULE_NOT_FOUND`
для `yaml`. До компиляции Astro команда не дошла. Это отсутствие зависимостей
в среде, **но оно не доказывает**, что после их установки сборка пройдёт без
других ошибок. Успех полного `astro build` не заявляется.

Не были выполнены: реальный рендер всех страниц Astro, окончательная проверка
CSS-скоупинга и оптимизации изображений, Astro-generated types, работа sitemap/
редиректов/404 в сгенерированном dist, postbuild на настоящем результате сборки,
открытие CMS с авторизацией, публикация GitHub Actions.

## Что проверить владельцу после установки зависимостей

```sh
npm ci
npm test
npm run build
npm run preview
```

Получите успешный build. Проверьте все 15 основных страниц на трёх языках,
мобильный/планшетный/настольный размеры, одинаковый раздел при смене языка,
якоря услуг, навигацию клавиатурой, настоящие ссылки и новые изображения.

Отдельно нужны отправка и получение реального письма, регистрация в настоящей
Google Forms, поступление события в ваш ресурс GA только после согласия,
отзыв согласия в обычном браузере, вход/сохранение в CMS, домен/DNS/HTTPS и
GitHub Pages с подпапкой/без неё. Подготовленный код этих подтверждений
не заменяет.

## Целостность пакета обновления

Git-патч проверен командой `git apply --check` и применён к отдельной чистой
копии исходного архива. Содержимое всех файлов затем сверено по SHA-256:
патч воспроизводит обновлённое дерево проекта. Проверка `git diff --check`
не обнаружила ошибок добавленного форматирования. Это проверка переноса
исходников, а не замена сборки или тестирования интеграций.
