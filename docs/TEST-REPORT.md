## Полная сборка — не подтверждена

npm-реестр registry.npmjs.org недоступен по DNS. Зависимости не установлены;
локальный npm run build не дошёл до Astro. Это ограничение среды подготовки,
а не подтверждение успешной или неуспешной компиляции обновлённого сайта.
Зависимости и package-lock.json сохранены без изменений.

После настоящего npm run build автоматически выполняются
`tests/check-contacts-build.mjs` и `tests/check-full-build.mjs`.
Проверяется HTML всех 15 страниц до публикации. Логика этих анализаторов отдельно
проверена на корректных изолированных HTML-фикстурах; это НЕ результат сборки.
Успешную компиляцию должен подтвердить новый GitHub Actions run.
