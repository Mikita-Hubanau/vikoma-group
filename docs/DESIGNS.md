# Пять раскладок Signature — редакция 1.3.0

## Одна палитра

`src/styles/designs.css` задаёт единые переменные для всех допустимых раскладок:
белый `#FFFFFF`, светло-серый `#F5F5F5`, графит `#1A1A1A`/`#2D2D2D`, приглушённое
золото `#C49A45`. Более тёмное золото `#8B692B` используется для текста/линий,
светлая поверхность `#F6F3EC` — для мягкой подложки. Основные кнопки золотые
с графитовым текстом. Подвал тёмный. Новые цветовые акценты не добавлены.

Палитра взята из прежнего дизайна 04, без перехода на оливковые/терракотовые
варианты. Логотип и favicon используют исходное золото заказчика `#B78C42`;
browser theme-color остаётся графитовым. Подробнее: `BRANDING.md`.
Тени, градиенты и декоративный шум в новых раскладках не используются.

## Различия композиций

| Кнопка / ID | Главная | Внутренние разделы |
|---|---|---|
| 01 `signature` | Сохранён прежний центрированный первый экран 04; карта ниже, услуги в четырёх колонках на широком экране | Симметричные заголовки, центрированные карточки команды и офисы |
| 02 `balance` | Текст слева, карта справа; парные карточки услуг с иконками | Двухколоночные заголовки; рамки карточек, услуги с боковым заголовком |
| 03 `editorial` | Узкое левое поле, широкий заголовок, ниже текст и карта; услуги горизонтальными строками | Команда и офисы строками на широком экране; регистрация после программы |
| 04 `atlas` | Карта в большой левой панели, текст справа; слева вводный блок услуг, справа сетка 2×2 | Модульные карточки команды/офисов, услуги в два столбца; последняя на всю ширину |
| 05 `panorama` | Заголовок на всю ширину; ниже карта слева и вводный текст справа; услуги в колонках | Широкая ось, центрированные заголовки, услуги последовательными секциями, регистрация под программой |

На мобильных экранах сложные сетки превращаются в текстовую последовательность.
Основная информация не скрывается ради красивого макета. Отступы и рамки остаются
разными. На узком экране сначала видны название и языки, ниже все пять кнопок,
затем меню. У кнопок есть номер, миниатюра, имя, локализованная подсказка и ARIA.

## Реализация

Один DOM и один набор контента. Выбор меняет `html[data-design]`; стандартные
стили компонентов служат основой, файл `src/styles/designs.css` задаёт палитру
и геометрию. Корневой `id="vikub-site"` сохраняется для приоритета над scoped CSS
Astro. Для некоторых настольных сеток используется `display:contents` только
на нейтральной обёртке текста hero. Сам H1, ссылки, формы и их порядок в DOM
не перемещаются JavaScript и не дублируются.

ID: `signature`, `balance`, `editorial`, `atlas`, `panorama` — в этом порядке.
Они согласованы в библиотеке, bootstrap, клиентском скрипте, CMS и проверках.
Приоритет: валидный URL `?design=…`, сохранённый `vikub-design`, defaultDesign.
Клиент не отправляет выбор на сервер. Без JS отображается `defaultDesign`.

Параметры `defaultDesign`/`showSwitcher` — в `src/content/system/design.json`.
Старые ссылки `signature` продолжают работать; `original`/`grid` больше не
являются допустимыми темами. Набор из пяти старых цветов заменён пятью раскладками.

## Превью и проверки

`preview/VIKUB-layout-preview.html` производен от предоставленного автономного
превью предыдущей редакции. В редакции 1.3 обновлены брендовые изображения, общие компоненты,
тексты и связанные стили. Содержимое проверено против текущих JSON-файлов.
Это не компиляция Astro. Пакеты шрифтов Fontsource остаются зависимостями проекта,
в HTML используются системные шрифты; их переносы могут отличаться.

```sh
npm test
python tests/revision_browser_checks.py
python tests/layouts_preview_checks.py preview/VIKUB-layout-preview.html
python tests/brand_preview_checks.py preview/VIKUB-layout-preview.html
python tests/preview_layout_checks.py preview/VIKUB-layout-preview.html
```

Браузерные проверки требуют Playwright и Chromium. Последние три команды
проверяют снимок, а не пересобирают его и не подменяют `npm run build`.
