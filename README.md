# VIKUB — сайт с пятью вариантами оформления

Редакция 1.1.0 по новым правкам владельца. Основа — ранее переданный архив
`vikub-group-updated.zip`. Исходный репозиторий: `Mikita-Hubanau/vikoma-group`.
Бренд на сайте: **VIKUB**. Итальянский — основной язык, английский и русский — дополнительные.

Сохранены Astro, Sveltia CMS, векторная карта и существующие возможности
редактирования. Никакие изменения не опубликованы в GitHub, на домене или в аккаунтах сервисов.

## Запуск

В папке с `package.json`, используя Node.js не ниже версии из `engines`:

```sh
npm ci
npm run dev
```

Перед публикацией:

```sh
npm test
npm run build
npm run preview
```

Полная сборка Astro **не проверена в среде подготовки**: зависимости npm
не удалось получить. Успешные тесты исходников и браузерных модулей не заменяют
эту проверку. Подробности: [отчёт](docs/TEST-REPORT.md).
Версии зависимостей и разрешённые версии lock-файла сохранены; изменены только
название и версия самого проекта. Массовое обновление пакетов не требуется.

## Пять оформлений

Под IT / EN / RU в шапке расположены пять кнопок. Они работают на главной
и на остальных публичных страницах. Меняются композиция, типографика,
карточки, первый экран, акценты и оформление внутренних разделов.

| Кнопка | Вариант / ID | Характер |
|---|---|---|
| 01 | Оригинал / `original` | Исходная визуальная система, карта справа, тёплый светлый фон |
| 02 | Editorial / `editorial` | Терракотовый, редакционная композиция, крупные заголовки с засечками |
| 03 | Atlas / `atlas` | Оливковый, деловой гротеск, карта слева на широком экране, модульные карточки |
| 04 | Signature / `signature` | Приглушённое золото, центрированный первый экран, тонкие линии |
| 05 | Grid / `grid` | Графит, небольшие терракотовые детали, строгая сетка и сильная типографика |

При первом посещении выбран **оригинал**. Выбор запоминается, включая переходы
между языками. В приватном режиме есть резервная передача выбора в URL.
Без JavaScript отображается дизайн по умолчанию; интерактивные переключатели требуют JavaScript.

В CMS: **Общие подключения и служебное → Оформление сайта**.
В файлах: `src/content/system/design.json`.

```json
{
  "defaultDesign": "original",
  "showSwitcher": true
}
```

Чтобы закрепить выбранный вариант и скрыть кнопки, измените эти поля и
пересоберите сайт. Сохранённый ранее выбор посетителя имеет приоритет над
`defaultDesign`; параметр `?design=editorial` позволяет явно открыть нужный вариант.
Подробности и палитры: [DESIGNS.md](docs/DESIGNS.md).

## Страницы и языки

| Раздел | IT — основной | EN | RU |
|---|---|---|---|
| Главная | `/` | `/en/` | `/ru/` |
| О нас | `/azienda/` | `/en/about/` | `/ru/o-kompanii/` |
| Услуги | `/servizi/` | `/en/services/` | `/ru/uslugi/` |
| Мероприятия | `/eventi/` | `/en/events/` | `/ru/meropriyatiya/` |
| Контакты | `/contatti/` | `/en/contacts/` | `/ru/kontakty/` |

На GitHub Pages в подпапке перед каждым путём добавляется base path.
Прежние `/it/...`, русские непредварённые адреса и страницы отраслей сохранены
как страницы перенаправления. Старый адрес `/` теперь намеренно итальянский.
Это статические HTML-перенаправления, а не серверный HTTP 301.

## Контент и формы

Название, команда, эксперты, НАИП, партнёры, услуги и программа семинара
обновлены на всех трёх языках. Семинар — **1 октября 2026, 10:00 Europe/Rome**,
онлайн в Zoom. Время и дедлайн заданы в `src/content/system/seminar.json`.

Встроенная регистрация содержит имя, фамилию, компанию, email, необязательный
телефон и согласие. **Без настоящего HTTPS-обработчика она выключена.**
Данные не сохраняются локально, успешная отправка не имитируется.
