# VIKUB — пять раскладок Signature, логотипы и финальные тексты

Версия **1.3.0**. Основа — `VIKUB-Signature-5-layouts.zip` (1.2.0).
Сайт на Astro с общей палитрой, пятью раскладками, CMS и языками IT / EN / RU.
Итальянский основной: `/`; английский: `/en/`; русский: `/ru/`.

## В этой версии

Подключены предоставленные SVG-логотипы: шапка, тёмный подвал, favicon,
иконка устройства и карточка ссылки. Везде используется слоган
**Italy meets Eurasia**. Главный заголовок сокращён, партнёры представлены
общими текстовыми блоками на главной и «О нас». Обновлены биографии и сеть
экспертов. В контактах оставлены только города; соцсети перенесены в правую
колонку подвала. Семинар: 1 октября 2026, 10:00, восемь финальных пунктов.

Раскладки: **Signature, Balance, Editorial, Atlas, Panorama**. Переключатели
под языками, сохранение выбора и мобильная версия сохранены.

## Просмотр и запуск

Откройте `preview/VIKUB-layout-preview.html` для просмотра без установки.
Это автономный визуальный снимок, **не сборка Astro**; формы отключены,
шрифты системные. Публиковать нужно проект, а не этот HTML.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Полная сборка в среде подготовки не подтверждена: npm-реестр недоступен,
нет зависимостей. Изолированные тесты и их границы — в отчёте ниже.
Новые npm-зависимости не добавлялись, версии пакетов сохранены.

Контакты, соцссылки и обработчики форм не выдумывались. Настройка email
сама по себе не включает отправку сообщений. В GitHub и на действующий сайт
эта редакция не публиковалась.
