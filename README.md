# VIKUB — Balance, обновление по подробному ТЗ

Сайт на Astro: итальянская версия `/`, английская `/en/`, русская `/ru/`.
Оставлен только согласованный второй макет **Balance**. Переключателя вариантов,
его сохранения в браузере и стилей остальных вариантов больше нет.

Обновлены главная, услуги, команда, мероприятия и контакты на трёх языках.
Подробности: [изменения](docs/CHANGES.md), [проверки](docs/TEST-REPORT.md),
[публикация](docs/LAUNCH.md), [дизайн](docs/DESIGNS.md),
[пункты ТЗ и недостающие материалы](docs/BRIEF-STATUS.md).

## Быстрая публикация

Распакуйте архив обновления и загрузите **содержимое `UPLOAD`** в корень ветки
`main` через Add file → Upload files. Саму папку UPLOAD и ZIP не загружайте.
Сохраните непосредственно в main и дождитесь нового запуска
«Публикация на GitHub Pages». Ручное удаление папок не требуется.

Обработчик `public/api/contact.php` также нужно заменить на реальном PHP-хостинге
как `/api/contact.php`, если формы используют этот обработчик. GitHub Pages его
не исполняет. Настройки интеграций, адреса получателей и журналов сохранены.

## Локальная работа

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Сборка автоматически проверяет CMS, контент, Node-тесты, затем готовые HTML всех
15 публичных страниц. Зависимости и package-lock.json не обновлялись.

Полная сборка Astro в среде подготовки **не подтверждена**: npm-реестр недоступен.
Пройдены исходные, браузерные и изолированные PHP-проверки; это не заменяет
успешную сборку в GitHub Actions и реальную проверку получения писем.

## Макет без установки

`preview/VIKUB-layout-preview.html` — изолированный макет по новым данным и стилям,
**не результат компиляции Astro**. Все 15 страниц доступны через список сверху.
Формы ничего не отправляют. Используются шрифты браузера, не файлы шрифтов проекта.
На сайт публикуется проект, а не этот HTML.

## Чего нет в исходных материалах

Нет фотографий трёх участников и логотипов двух партнёров. Места для настоящих
изображений готовы: у команды круги 200×200, у партнёров связанные с адресами
логотипы и подписи; до загрузки используются инициалы и текстовые названия.
Нет исходного текста «Для кого мероприятие»: предусмотрено редактируемое поле,
пустой блок не публикуется. Восемь исходных тем программы сохранены полностью.
