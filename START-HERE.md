# С чего начать

Это обновлённый проект **Vikub Group** по вашему ТЗ. На GitHub и на домен
он автоматически не загружен.

## 1. Посмотрите сайт локально

Распакуйте архив в отдельную папку. Откройте терминал в ней:

```sh
npm ci
npm run dev
```

Перейдите по адресу из терминала. Нужно подключение к интернету для установки
npm-зависимостей. Node.js — не ниже 22.12.0; workflow использует Node.js 24.

## 2. Заполните то, чего нет в ТЗ

В `/admin/`, раздел «Общие подключения и служебное», нужны три значения:
реальная ссылка Google Forms, HTTPS-адрес обработчика писем, ID Google Analytics.
В «Общее» — настоящие контакты, соцсети, названия и логотипы партнёров.
Пока их нет, сайт честно показывает, что контакт/регистрация недоступны.

Подробности — `docs/LAUNCH.md`. Форма не начнёт отправлять письма только
от добавления адреса почты: нужен подключённый сервис обработки формы.

## 3. Обновите репозиторий

Самый безопасный способ для разработчика — применить прилагаемый Git-патч
к чистой версии, совпадающей с вашим исходным архивом. Сначала `git apply --check`,
затем `git apply`. Патч добавляет новые файлы и удаляет заменённые старые.

При переносе файлов вручную замените папки `src/content/services/ru`, `it`, `en`
целиком. Не оставляйте в них старые услуги. Остальные изменения перенесите
из обновлённого архива, сохранив вашу локальную папку `.git` и реальные секреты.
Сначала сохраните отдельную копию текущего проекта.

Перед публикацией:

```sh
npm test
npm run build
npm run preview
npm run check:launch
```

Последняя команда сейчас ожидаемо сообщает о незаполненных подключениях и
материалах. Это отдельная проверка готовности, а не ошибка разметки.
